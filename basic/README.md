# Evelyn, BASIC edition

Written in the QuickBASIC dialect so that FreeBASIC (`-lang qb`) can build it for DOS, Windows, Linux and Raspberry Pi.

```powershell
build.bat                                  # fbc -lang qb: evelyn.exe and evelyn_proto.exe   (build.sh on Linux)
evelyn.exe [TINY.BIN] [book.txt]           # keeps USER.CFG and LIBRARY.EVL in the current folder
node ..\tests\qbi.js evelyn.bas            # same program in the bundled interpreter, no compiler needed
```

Files:

| File | Contents |
| --- | --- |
| `evelyn_core.bi` | all the logic: text helpers, LZW and base64, library, `TNY2` engine, profile, coding lab, adventure, tutor |
| `evelyn_data.bi` | starter facts, rooms and lessons; generated from the JavaScript edition by `tools\gen_data.js` |
| `evelyn_io.bi` | file and escape helpers shared by the two programs |
| `evelyn_decl.bi` | `DECLARE` lines for every procedure; generated by `tools\gen_decl.js` |
| `evelyn.bas`, `evelyn_proto.bas` | the terminal program and the conformance driver |

What differs from the JavaScript edition: no `KV21` export or import (a primed prefix works), no sampling (answers take the best token), no several-shelf checker, no packets. The LZW dictionary stops at 4095 codes, so a single text longer than a few thousand characters compresses to different codes than in the other editions (it still decompresses everywhere), and the library holds 1000 entries. The model tables are sized for the real `TINY.BIN` (width 96, 4 layers, hidden size 256) and use about 700 KB as 16-bit integers.

Rules the source follows, because the dialect has 16-bit `INTEGER` and `SINGLE` arithmetic:

- Anything that can pass 32767 is `LONG` (string positions, table offsets), and one factor of each product is `CLNG`.
- Every sum or product over `SINGLE` data goes through `CDBL`, so it is added up in `DOUBLE` as the other editions do. Float literals carry `#` or `!`.
- Names start with a lower-case type letter (`i`, `l`, `s`, `d`, `a`, `g`) and avoid keywords. BASIC ignores case, so `iF`, `sIn`, `aS` and `aBs` are `IF`, `SIN`, `AS` and `ABS`; `node ..\tools\check_bas_names.js` finds such names.
- A missing file is detected by opening it for `BINARY` and checking `LOF`, then deleting the empty file this creates.

The program has not been compiled with FreeBASIC. See the top-level README for what the interpreter does and does not prove.
